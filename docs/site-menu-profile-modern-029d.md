## Проблема
- В шапке дубли («Новости» в основном ряду и в «Ещё» из‑за overflow; «Дом молодёжи» несколько раз из QA/seed).
- Аккаунт: отдельные иконки профиля / кабинета / выхода без единого меню.
- В кабинете «Профиль» и «Настройки» как равноправные пункты, «Чат» ≠ «Сообщения».
- Подвал — плоский список без групп; CMS-страницы могли дублировать основные разделы.

## Сделано
- `nav-catalog.ts`: дедуп названий + приоритет crm/seed; navbar без `isDemoData`.
- Аккаунт-меню в шапке (Моя страница / Кабинет / Редактировать / Настройки / Сообщения / Друзья / Выйти).
- «Ещё» / «Разделы»: секции «Скрытые пункты» и «Ещё на сайте»; CMS без дублей primary-slug.
- Кабинет: один «Профиль», группы с разделителями, «Сообщения»; портфолио в хабе профиля.
- Подвал: колонки Смотреть / Участвовать / Информация + вакансии/конкурсы.
- Каталоги spaces/projects/clubs: скрыт demo-data.
