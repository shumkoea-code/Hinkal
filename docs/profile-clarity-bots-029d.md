# Профиль / настройки и модерация через бота

Дата: 2026-08-10  
Прод: https://young.idivles.ru  
Образ: `sochi-portal_web:profile-clarity-bots`

## Проблема
- В кабинете не было явных пунктов «Профиль» и «Настройки»; безопасность спрятана в аккордеоне обзора.
- Редактирование — только иконка карандаша; «Портфолио» путали с просмотром профиля.
- Часть всплывающих окон (admin-modal) перекрывалась шапкой (`z-index: 1000` vs nav `1200+`).
- На `/admin/bots` не было пошагового сценария модерации кнопками в MAX/Telegram.

## Сделано

### Кабинет
- В боковом меню: **Профиль** и **Настройки**.
- Вкладки профиля: Обзор / Редактировать / Настройки.
- Обзор: быстрые ссылки «Редактировать», «Настройки сайта», «Как видят другие».
- Настройки: сессии/устройства, фраза восстановления, удаление, согласия, подсказка про MAX/Telegram ID.
- Иконка шестерёнки рядом с карандашом в шапке кабинета.
- Быстрый доступ: кнопка настроек → `?tab=profile&section=settings`; хоткей `G U`.

### Модалки
- `.admin-modal-backdrop` поднят до `z-index: 12000` (как `rep-modal`), чтобы диалоги не прятались под навигацией.

### Админка → Боты
- Блок **«Как модерировать через бота»**: привязка ID → включение бота → кнопки Одобрить/Отклонить → очереди на сайте → журнал.
- Ссылки на `/admin/moderation`, заявки, брони, `/admin/activity?category=bots`.
