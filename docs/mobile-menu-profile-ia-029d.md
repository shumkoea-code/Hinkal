# Мобильное меню: профиль отдельно от настроек

Дата: 2026-08-10  
Прод: https://young.idivles.ru  
Образ: `sochi-portal_web:mobile-menu-profile-ia`

## Идея IA (без копирования чужих брендов)
Структура как у привычных мобильных «Ещё»-экранов:
- карточка **личности** → публичный профиль;
- **настройки** — только шестерёнка в шапке листа;
- списки разделов кабинета и сайта с иконками.

Визуал — светлая тема портала, свои иконки Lucide, без тёмной «VK-темы» и чужих ассетов.

## Маршруты
- Карточка профиля → `/u/...` («Открыть профиль»)
- Шестерёнка → `/dashboard?tab=profile&section=settings`
- Список: кабинет, билеты, сообщения, друзья, ачивки, портфолио + разделы сайта
