# Profile safety + UX (Надёжность / Сообщество, модерация фото)

Дата: 2026-08-10  
Прод: https://young.idivles.ru  
Образ: `sochi-portal_web:profile-safety-ux`

## Что сделано

### Кликабельность и каталог
- Навбар «Проекты / Клубы / Пространства»: кнопки-триггеры + hover; убран `overflow: hidden` у `.desktop-nav` (дропдауны больше не 0×0); desktop-nav с ~1100px+.
- Карточки проектов → `/projects/[id]`.
- Карточки пространств: hit-link не перекрывается inert z-index.

### Рейтинги
- **Авторитет → Надёжность** (приходы, заявки, брони).
- **Социум → Сообщество** (друзья, галерея, чат).
- Два показателя намеренно разные; в модалке — зачем каждый и история.

### Безопасность профилей
- `profile-text-guard` + расширенный `censor`.
- Регистрация/профиль: имя, био, about, теги.
- SQL-скан → `PROFILE_TEXT` (`ytyt tytyty` в очереди модерации).

### Модерация фото
- `GALLERY_IMAGE` / `AVATAR_IMAGE`, статусы PENDING/APPROVED/REJECTED.
- Публичный профиль — только одобренные; авто-approve при надёжности ≥ 92 / staff.
