# Profile safety + UX (Надёжность / Сообщество, модерация фото)

Дата: 2026-08-10  
Прод: https://young.idivles.ru  
Образ: `sochi-portal_web:profile-safety-ux` (после деплоя)

## Что сделано

### Кликабельность и каталог
- Навбар «Проекты / Клубы / Пространства»: hover открывает меню, первый клик — меню, повторный — переход в раздел; Ctrl/⌘-клик всегда ведёт на страницу.
- Карточки проектов ведут на `/projects/[id]`, а не только `?tab=`.
- Карточки пространств: убран «мертвый» z-index поверх hit-link (чипы/адрес больше не блокируют клик).

### Рейтинги
- **Авторитет → Надёжность** (приходы, заявки, брони).
- **Социум → Сообщество** (друзья, галерея, чат).
- Метрики **не сливаются**: разные смыслы и лимиты; в модалке «Рейтинги и история» объяснение + история по вкладкам.
- Усилены pointer-events/z-index у чипов рейтинга.

### Безопасность профилей
- `profile-text-guard`: реальные имена (буквы, без gibberish вроде `ytyt tytyty`), лимиты слов.
- Расширен словарь `censor.ts`.
- Регистрация + обновление профиля: имя/био/about/теги.
- Скрипт `scripts/scan-profile-safety.ts` — флаги `PROFILE_TEXT` в модерации.

### Модерация фото
- Галерея/аватар → очередь `ContentFlag` (`GALLERY_IMAGE` / `AVATAR_IMAGE`).
- Статусы фото: `PENDING` / `APPROVED` / `REJECTED`; публичный профиль видит только одобренные.
- Авто-одобрение при надёжности ≥ 92 или роли staff.
- Админка модерации: превью фото, кнопки «Одобрить / Отклонить».

## Свежие регистрации (аудит)
Подозрительные имена 2026-08-10: `ytyt tytyty`, `Али КилиАбра…` — после деплоя попадают в scan/флаги; новые такие имена регистрация отклонит.
