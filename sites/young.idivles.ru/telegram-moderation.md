# Telegram-модерация заявок и броней

Практичный поток согласования без захода в админку.

## Как пользоваться

1. Откройте `@Youngportalbot` → **/start** (если ещё не писали боту).
2. Убедитесь, что ваш chat id в **Настройки → Оповещения** или в **профиле** сотрудника.
3. Админ один раз: **«Подключить модерацию (вебхук)»**.
4. При новой заявке / брони в чат приходит карточка:
   - **Одобрить** / **Отклонить**
   - ссылка **Открыть в админке**
5. В любой момент: **/pending** — вся очередь PENDING.

## Поведение

- Решение сразу пишет статус в БД (`APPROVED` / `REJECTED`).
- Для броней при одобрении проверяется пересечение по времени (как в админке).
- Пользователю уходит обычное уведомление (in-app + email, если настроено).
- После решения сообщение в Telegram обновляется штампом «кто / когда».
