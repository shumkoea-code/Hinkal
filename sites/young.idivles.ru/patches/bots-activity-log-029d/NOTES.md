# bots-activity-log-029d

## Боты — больше настроек и удобный статус
- Карточки статуса: MAX / вебхук / Telegram / связанные ID
- Оповещения по типам: заявки, брони, модерация, портфолио
- Тихие часы (МСК), текст приветствия /start
- События вебхука MAX, получатели из профилей, тест, последние действия
- Конфиг в `SiteSettings.botsConfigJson` (`src/lib/bots-config.ts`)

## Журнал действий пользователей
- Модель `UserActionLog` + `logUserAction` / `voidLogUserAction`
- Админка **Активность** (`/admin/activity`) с фильтрами и статистикой по категориям
- Пишется: профиль, заявки, настройки/тесты ботов (и расширяется дальше)
- Без паролей/токенов (scrub)
