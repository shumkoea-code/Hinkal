# Реферальная система + окно инструктажа

## Рефералы
- Ссылка: `/r/R-XXXX` или `/register?ref=R-XXXX` (cookie `yp_ref` 30 дней).
- В кабинете → Профиль: блок «Пригласи друзей» (код, копирование, статистика).

### Награды (эко / социум / авторитет)
| Событие | Рефереру | Рефералу |
|--------|----------|----------|
| Регистрация (после антифрода) | до +8 эко, +1 социум | +5 эко |
| Инструктаж пройден | +5 эко, +1 социум | (уже GUIDE_COMPLETE) |
| Check-in на мероприятии | +25 эко, +2 социум, +1 авторитет | +10 эко |
| Профиль заполнен | +6 эко, +1 социум | +4 эко |
| Стали друзьями | +8 эко, +2 социум | +4 эко |
| Вехи 3 / 10 check-in | +40 / +120 эко | — |

Лимиты реферера: 80 эко/сутки, 320/неделя с рефералов.

### Антифрод
- Один пригласивший на аккаунт.
- Self / то же устройство / velocity IP·fingerprint → REJECTED.
- Крупные награды только если реферер «зрелый» (возраст/инструктаж/авторитет ≥ 60).
- Check-in-бонус не раньше чем через 2 ч после регистрации реферала.
- Идемпотентный `ReferralReward` (`referralId+kind`).

## Инструктаж при входе
Модалка: **Пройти** / **Пропустить** / **Больше не показывать**  
(`instructionsPromptDismissedAt` + localStorage).
